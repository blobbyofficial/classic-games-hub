# v1.6.1 release follow-up — visual polish, developer perks, Level 25 themes

## Already deployed (19 October 2026)
PR #82 deployed the five-theme frontend and repaired the Next.js font build. The site's update log now records this as **v1.6.1 — Five Themes, One Arcade**. The precise live database migration state is not yet independently verified.

## Follow-up changes in this branch (not live until separately released)
- **Basic appearance:** Make the common text gradient use theme accent variables, not the legacy Halloween-like `--gold`. Keep `--gold` for coin/reward semantics. Restore deliberate violet and pink accents in Basic and give the hero subtle depth in Light and Dark.
- **Shared logo:** Keep the true `/icon.svg` artwork on a stable black plate; use readable solid wordmark text rather than inherited gradient that changes unexpectedly with modes.
- **Buttons:** Use theme variables for gradient CTAs instead of fixed pink.
- **Developers:** The database currently supports only `user`, `moderator`, and `admin`. Developer access is represented by `admin`; migration 0115 grants admin accounts the booster daily multiplier, monthly booster cosmetic, and monthly gift token without forging Discord `booster_since`. Existing admin/moderator eligibility for challenges and restricted theme previews remains.
- **Level 25:** Keep permanent Retro unlock from 0114 and also allow Premium Atelier at Level 25, even without a server boost. The app's theme picker and authoritative database guards use the same rules. Existing eligible high-level users are recognised immediately by the RPC; a reissued award is not required.
