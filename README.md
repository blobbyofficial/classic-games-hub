# Classic Games Hub

Static retro arcade site rebuilt from scratch.

Main routes:

- `index.html` - landing page
- `pages/homepage.html` - game library
- `pages/gamepage.html` - field guide
- `pages/snake.html` - Snake detail page
- `pages/tetris.html` - Tetris detail page
- `games/snake/snake-game.html` - playable Snake
- `games/tetris/tetris-game.html` - playable Tetris

The site shell is plain HTML and CSS with direct links between pages. No manifest fetches or query-string driven content rendering are required to browse it.
